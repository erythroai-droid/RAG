# 📌 Obsidian Knowledge Base — AI Agent Rules

## 🚨 Обязательное правило синхронизации с GitHub (Git Push on Changes)

Каждый раз, когда ты (AI-агент) добавляешь, изменяешь, переименовываешь или удаляешь файлы/заметки в этой базе знаний (`Knowledge-Base`):

1. **ОБЯЗАТЕЛЬНО** сделай коммит и отправь изменения в удаленный репозиторий GitHub:
   ```bash
   git add .
   git commit -m "<тип>(<раздел>): <описание изменений>"
   git push origin main
   ```
2. **Удаленный репозиторий:** `https://github.com/erythroai-droid/RAG.git` (ветка `main`).
3. **Сохранение целостности:**
   * Всегда обновляй ссылки в `index.md` при добавлении новых файлов.
   * Поддерживай формат YAML Frontmatter в начале заметок.
