# 🎨 Дизайн-система «Erythro Pulse» (Dynamic Modern Fintech)

> **Концепция:** Синтез лучших практик **Mercury Bank** (воздух, благородство, масштабные заголовки), **Brex** (контраст, ясные акценты), **Ramp** (живая интерактивность, реакция на наведение, динамический фон) и **Wealthfront** (векторная визуализация данных, отсутствие скучных таблиц).

## 2. Типографика и шрифтовые пары

Учитываем строгие требования к трем языкам проекта (**RU, EN, HE**):

| Язык | Основной гарнитур | Альтернатива | Моноширинный (Данные, теги) |
|---|---|---|---|
| **English (EN)** | **Inter** (оптимизированные метрики, `tracking-tight`) | **Plus Jakarta Sans** (более геометричный и современный финтех-характер) | **Roboto Mono** / **JetBrains Mono** |
| **Русский (RU)** | **Inter Cyrillic** (полная поддержка кириллицы, идеальный хинтинг) | **Plus Jakarta Sans** (с кириллической веткой) | **Roboto Mono** |
| **Иврит (HE)** | **Heebo** (идеален для RTL, гармонирует по высоте x-height с Inter) | **Assistant** (современный гротеск для иврита) | **Roboto Mono** (числа строго `dir="ltr"`) |

### Типографическая шкала (Desktop / Mobile):
* **Hero Display H1:** `clamp(44px, 5.5vw, 76px)` — `font-bold leading-[1.05] tracking-[-0.035em] text-balance`
* **Section Title H2:** `clamp(28px, 3.2vw, 42px)` — `font-bold leading-[1.15] tracking-[-0.025em]`
* **Subheading / Lead:** `clamp(16px, 1.3vw, 19px)` — `font-normal leading-[1.6] text-slate-600`
* **Card Titles H3:** `18px–20px` — `font-semibold leading-snug`
* **Body / Inputs:** `15px–16px` — `font-medium leading-normal`
* **Micro Tags / Meta:** `11px–12px` — `font-mono uppercase tracking-[0.06em]`

## 3. Геометрия, Скругления и Тени

### Сетка и отступы:
* **Ширина контентной зоны:** `max-w-[1440px]` для широких экранов с безопасными полями `px-6 md:px-12 lg:px-16`.
* **Ритм отступов (кратный 8px):** 
  * Микро: 4px, 8px, 12px
  * Компонентные: 16px, 24px, 32px
  * Секционные: 48px, 64px, 80px

### Скругления (Radii Hierarchy):
* **`rounded-[6px]` / `rounded-md`:** Технические бейджи, моно-теги, сегменты степпера.
* **`rounded-[12px]` / `rounded-xl`:** Инпуты полей ввода, карточки проверок «Что проверяет лаборатория», чекбоксы.
* **`rounded-[20px]` / `rounded-2xl`:** Главный белый контейнер формы, фактоиды.
* **`rounded-[24px]` / `rounded-3xl`:** Внешняя контентная сплит-панель.
* **`rounded-full`:** Главная CTA-кнопка, индикаторы статуса.

### Тени и глубина (Ambient Depth):
* **Карточки по умолчанию:** `shadow-[0_1px_3px_rgba(0,0,0,0.03),0_4px_12px_rgba(0,0,0,0.03)]`
* **Карточки при наведении (Hover State в стиле Ramp):** `-translate-y-1 shadow-[0_12px_32px_-4px_rgba(15,23,42,0.08),0_4px_12px_rgba(15,23,42,0.04)]` + подсветка рамки.
* **Кнопка действия:** `shadow-[0_4px_16px_rgba(229,36,33,0.22)] hover:shadow-[0_8px_28px_rgba(229,36,33,0.38)] active:scale-[0.99]`

## 4. UI-компоненты первого экрана

1. **Top Nav / Header:**
   * Просторный минималистичный хедер с официальным логотипом `Erythro.ai`.
   * Правый блок: языковой селектор (EN · RU · HE) в виде аккуратного сегментированного переключателя + статусная точка готовности лаборатории.
2. **Hero Offer (Левая колонка):**
   * **Super-badge:** Овальный бейдж с градиентной точкой: `● ЭКСПРЕСС-АУДИТ 2026 · AUTONOMOUS LAB`.
   * **Giant Headline:** Две строки масштаба Mercury: «Сколько денег теряет ваш сайт?» с акцентным рубиновым выделением.
   * **Lead Text:** Четкое, понятное и легкое для чтения объяснение (2 строки).
   * **Векторные карточки преимуществ (Wealthfront style):** 3 интерактивные плашки в горизонтальный ряд или 2x2 грид с векторными иконками, микро-прогрессбарами и реакцией на hover:
     * ⚡ Скорость и CWV: индикатор `99/100`
     * 🎯 Лид-формы и чекауты: проверка утечек
     * 🤖 AI-видимость: готовность к ChatGPT и Claude
3. **Card Shell (Правая колонка — Ramp style):**
   * **Интерактивный степпер:** 4 шага с мягкой линией прогресса, номерами и статусом `NOW`.
   * **Белоснежная карточка ввода:**
     * Контрастные поля ввода сайта и контактов с мягкими внутренними тенями и красивым фокус-кольцом.
     * Главная рубиновая кнопка во всю ширину со стрелкой `→` и интерактивным бликом.
     * 3 гарантии под кнопкой с элегантными изумрудными галочками.
