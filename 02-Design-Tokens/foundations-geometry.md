# 📐 Геометрия, Сетки и Отступы (Geometry & Layout)

#design-tokens #grid #spacing #layout #responsive #geometry

> **Назначение:** Стандарты адаптивной модульной сетки 1170px, системы отступов, радиусов скруглений и Auto-Layout констрейнтов.

---

## 1. Адаптивная 12-колоночная сетка (1170px Grid)

Основной контейнер интерфейса центрируется и ограничивается шириной `max-w-[1170px]`.

```css
/* Параметры десктопной сетки (Figma Spec) */
Max Width: 1170px;
Columns: 12;
Column Width: 70px;
Gutter (Расстояние между колонками): 30px;
Margin (Внешние поля): 30px (на мобильных: 16px - 20px);
```

### Классы Tailwind для разметки сетки:
- **Контейнер страницы:** `mx-auto max-w-[1170px] px-4 md:px-6 lg:px-8`
- **12-колоночный грид:** `grid grid-cols-1 md:grid-cols-6 lg:grid-cols-12 gap-6 lg:gap-[30px]`
- **Карточка 1/3 ширины:** `col-span-1 md:col-span-3 lg:col-span-4`
- **Карточка 1/2 ширины:** `col-span-1 md:col-span-3 lg:col-span-6`
- **Широкий блок 2/3:** `col-span-1 md:col-span-6 lg:col-span-8`

## 2. Шкала пространственных отступов (Spacing Scale)

| Имя токена | Значение (px) | Значение (rem) | Класс Tailwind | Типичное применение |
|---|---|---|---|---|
| `space-3xs` | 2px | 0.125rem | `p-0.5`, `gap-0.5` | Микро-индикаторы, бейджи |
| `space-2xs` | 4px | 0.25rem | `p-1`, `gap-1` | Внутренние бейджи |
| `space-xs` | 8px | 0.5rem | `p-2`, `gap-2` | Отступы между иконкой и текстом |
| `space-s` | 12px | 0.75rem | `p-3`, `gap-3` | Компактные кнопки, инпуты |
| `space-m` | 16px | 1.0rem | `p-4`, `gap-4` | Паддинг мобильных карточек |
| `space-l` | 24px | 1.5rem | `p-6`, `gap-6` | Паддинг десктопных карточек |
| `space-xl` | 32px | 2.0rem | `p-8`, `gap-8` | Разделители между секциями H3 |
| `space-2xl` | 48px | 3.0rem | `py-12`, `gap-12` | Отступы между блоками |
| `space-3xl` | 64px–80px | 4.0–5.0rem | `py-16 md:py-20` | Вертикальные отступы секций |
| `space-section` | 96px–120px | 6.0–7.5rem | `py-24 md:py-32` | Большие разделители секций |

## 3. Радиусы скруглений (Border Radius)

| Имя токена | Значение | Класс Tailwind | Элементы интерфейса |
|---|---|---|---|
| `radius-xs` | 4px | `rounded-xs` / `rounded-[4px]` | Теги, техиндикаторы, бейджи |
| `radius-s` | 8px | `rounded-lg` / `rounded-[8px]` | Поля ввода, кнопки, чипсы |
| `radius-m` | 12px–16px | `rounded-xl` / `rounded-2xl` | Карточки услуг, поп-апы, модалки |
| `radius-l` | 20px–24px | `rounded-3xl` | Большие секционные карточки, баннеры |
| `radius-full` | 9999px | `rounded-full` | Круглые кнопки, пилюли, аватары |

## 4. Правила Auto-Layout и адаптивных ограничений

1. **Flex & Wrap:** Для списков чипсов/тегов всегда используется `flex flex-wrap gap-2`.
2. **Min-Width-0:** При использовании flexbox внутри грида контейнеры с текстом обязаны иметь `min-w-0` для корректной работы `truncate` и предотвращения раздувания ширины.
3. **Безопасные зоны экрана (Safe Area Insets):** Для мобильных оверлеев и модальных окон учитываются `pb-safe` и `pt-safe`.
