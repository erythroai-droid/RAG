# 📖 Технический глоссарий (Technical Glossary)

#glossary #definitions #terms #concepts

> **Назначение:** Единый словарь терминов, аббревиатур и протоколов для синхронизации понятий между разработчиками и AI-ассистентами.

---

### **A**
- **ACP (Agentic Commerce Protocol):** Открытый протокол от OpenAI и Stripe для обнаружения товаров AI-агентами, управления корзиной и делегированного чекаута.
- **AST (Abstract Syntax Tree):** Древовидная структура данных, используемая редактором Lexical для хранения богатого текста в формате JSON.
- **Auto-Layout:** Принцип адаптивной верстки, основанный на гибких контейнерах (Flexbox/Grid), динамически подстраивающихся под длину контента.

### **C**
- **CLS (Cumulative Layout Shift):** Метрика стабильности верстки из Core Web Vitals. Измеряет суммарный сдвиг элементов при загрузке (цель < 0.05).
- **CSP (Content Security Policy):** Заголовок безопасности HTTP, определяющий доверенные источники скриптов, стилей и медиаресурсов.

### **D**
- **Drizzle ORM:** Легковесный TypeScript ORM, используемый в адаптере `@payloadcms/db-postgres` для взаимодействия с PostgreSQL.

### **G**
- **GSAP (GreenSock Animation Platform):** Промышленный стандарт JavaScript-библиотеки для высокопроизводительных веб-анимаций.

### **I**
- **IS 5568:** Израильский национальный стандарт доступности веб-сайтов (на базе международного WCAG 2.1 AA).
- **ISR (Incremental Static Regeneration):** Механизм Next.js для обновления статических страниц в фоне без полной пересборки сайта.

### **L**
- **LCP (Largest Contentful Paint):** Метрика скорости загрузки основного контента (цель < 2.0с).
- **Lexical:** Современный открытый фреймворк для текстовых редакторов от Meta, стандарт для Payload CMS 3.0.
- **LLMs.txt:** Стандартизированный текстовый файл в корне сайта (`/llms.txt`), предоставляющий структурированную карту знаний для языковых моделей.

### **M**
- **MCP (Model Context Protocol / SEP-1960):** Протокол Anthropic для безопасного подключения LLM-клиентов к внешним источникам данных и инструментам.

### **P**
- **Payload CMS:** Headless CMS нового поколения на базе TypeScript и Next.js с встроенной админ-панелью и гибкими схемами данных.

### **R**
- **RAG (Retrieval-Augmented Generation):** Подход к обогащению промптов LLM актуальной контекстной информацией из базы знаний перед генерацией ответа.
- **RTL (Right-to-Left):** Направление письма справа налево (иврит, арабский язык).

### **V**
- **Vary Header (`Vary: Accept, Accept-Language`):** HTTP-заголовок, указывающий прокси и кэширующим серверам отдавать разные версии документа в зависимости от заголовков клиента.
