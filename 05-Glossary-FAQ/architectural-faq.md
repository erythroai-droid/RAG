### В: Нужен ли Row Level Security (RLS) на Supabase, если мы ходим только через Payload / `DATABASE_URL`?
**О:** Полные политики `auth.uid()` — нет: приложение не использует Supabase Auth / Data API. Обязателен другой baseline: пустые PostgREST exposed schemas, `REVOKE` у `anon`/`authenticated` на `public`, без `GRANT … TO anon` на таблицы CMS (PIT-110, [[supabase-data-api-grants]]). RLS без политик на чувствительных таблицах — опциональный второй замок. Если клиентский проект отдаёт таблицы через supabase-js — RLS + grants + pgTAP обязательны. Регламент: [[supabase-rls]].
