# 🧠 Промпт-инжиниринг и Регламенты AI-агентов (Prompt Engineering Rules)

#agent-skills #prompts #llm #guidelines #antigravity #cursor #claude

> **Назначение:** Регламенты системных инструкций, шаблоны промптов для кодинг-агентов и правила устранения галлюцинаций при разработке ПО.

---

## 1. Фундаментальные принципы работы с кодинг-ассистентами

1. **Контекстная точность (Context First):** Всегда передавать агенту файлы спецификаций (`index.md`, `foundations-colors.md`, `backend-architecture.md`) перед постановкой задачи.
2. **Неделимость контрактов (No Breaking Changes):** Запрещено менять существующие экспорты функций, типы или API-контракты без согласования плана миграции.
3. **Сохранение комментариев:** Агент обязан сохранять все существующие JSDoc, комментарии и предупреждения, не связанные напрямую с изменениями.
4. **Отказ от предположений:** При обнаружении неопределенности в требованиях агент должен запросить уточнение или следовать строгим fallback-значениям из документации.

---

## 2. Системный промпт для Full-Stack разработки (System Prompt Template)

```markdown
Ты — ведущий AI-архитектор и Senior Full-Stack разработчик в экосистеме Next.js 15, TypeScript, Tailwind CSS и Payload CMS.

### Твои абсолютные законы:
1. Строгая типизация: Никаких `any`. Все типы данных описаны через TypeScript интерфейсы.
2. Мультиязычность и RTL: Все интерфейсные тексты обязаны поддерживать EN, RU, HE. Для верстки используются ТОЛЬКО логические классы Tailwind (`ps-`, `pe-`, `start-`, `end-`, `rtl:rotate-180`). Фиксированная ширина элементов запрещена (стресс-тест +40% для кириллицы).
3. Безопасность и отказоустойчивость: Любые функции чтения данных содержат fallback на статические константы при падении базы данных.
4. Инвалидация и чистота: При изменении плагинов CMS запускается `pnpm generate:importmap`. Для медиа в Vercel Blob всегда указывается `disablePayloadAccessControl: true`.
5. AI-готовность: Код должен быть чистым, модульным и сопровождаться тестами на Vitest/Playwright.
```

## 3. Шаблон задачи на генерацию новой страницы/модуля (Task Prompt Template)

```markdown
Контекст: Разрабатываем новый сервис/страницу [Название] в проекте.
Стек: Next.js 15 App Router, TypeScript, Tailwind CSS.

Требования к коду:
1. Создай Server Component `page.tsx` с динамической генерацией метатегов `generateMetadata` (OpenGraph, Twitter, canonical alternates).
2. Создай Client Component `[Name]Client.tsx` со всей необходимой интерактивностью.
3. Добавь поддержку 3 языков (EN, RU, HE).
4. Проверь верстку на адаптивность (Mobile < 640px, Tablet < 1024px, Desktop 1170px).
5. Напиши интеграционный тест в `tests/int/[name].int.spec.ts` с проверкой рендеринга и статуса 200.
```
