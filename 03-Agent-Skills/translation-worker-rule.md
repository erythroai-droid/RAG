# Translation Worker Rule (C:\agents\Translater)

> **Действует глобально для всех задач, репозиториев и проектов.**

При необходимости перевода любых текстов, маркетинговых материалов, интерфейсов (UI/Microcopy), лендингов, документации или рекламных креативов с русского языка на **английский (EN)**, **иврит (HE)** или **арабский (AR)**, а также для аудита и валидации готовых переводов:

## 1. Обязательный воркер
Всегда использовать специализированный агент-воркер **`C:\agents\Translater`**.
- **Интерпретатор / Virtualenv**: `C:\agents\Translater\.venv\Scripts\python.exe`
- **CLI точка входа**: `C:\agents\Translater\cli.py`
- **Директория воркера**: `C:\agents\Translater`

## 2. Стандарты использования через CLI

### А. Перевод фразы или короткого текста:
```powershell
C:\agents\Translater\.venv\Scripts\python.exe C:\agents\Translater\cli.py "<исходный_текст_на_русском>" --style "<стиль>"
```
**Доступные стили (`--style`):**
- `UI/Microcopy` — для кнопок, форм, посадочных страниц, офферов и рекламных объявлений в Facebook/Google.
- `Developer/Engineering` — по умолчанию, для IT-терминологии, сленга и кода.
- `Documentation/RFC` — для документации, инструкций и официальных отчетов.

### Б. Перевод файлов целиком (Markdown, TXT, JSON):
```powershell
C:\agents\Translater\.venv\Scripts\python.exe C:\agents\Translater\cli.py --file "<путь_к_файлу.md>" --out-en "<путь_en.md>" --out-he "<путь_he.md>" --out-ar "<путь_ar.md>"
```

### В. Аудит и валидация существующего перевода (Review Mode):
```powershell
C:\agents\Translater\.venv\Scripts\python.exe C:\agents\Translater\cli.py --review "<русский_оригинал>" --translation "<проверяемый_перевод>" --lang <en|he|ar>
```

## 3. Ключевые требования к качеству и отображению (BiDi / RTL)
1. **Строгая проверка отображения справа-налево (RTL) в рекламе и интерфейсах:**
   - **Проблема**: В рекламных кабинетах Meta Ads (Facebook/Instagram), Google Ads и на сайтах при смешении иврита с английскими словами (`AI`, `SEO`, `URL`), цифрами (`0–100`, `2`, `3`) и знаками препинания (`?`, `!`, `:`, `—`, `.`) знаки и слова «скачут» (вопросительный знак прыгает в начало строки, цифры инвертируются, латиница ломает порядок чтения).
   - **Обязательное правило форматирования**:
     - Каждая строка текста на иврите/арабском должна начинаться и заканчиваться невидимым маркером направления справа-налево (**RLM**: `\u200F`).
     - Любые латинские вкрапления (`AI`, `SEO`, `Next.js`) и числовые диапазоны (`0–100`) должны оборачиваться маркерами `\u200F<слово>\u200F`, чтобы зафиксировать контекст RTL.
     - Обязательно проверять визуальный рендеринг в окне предпросмотра объявления (Ad Preview) перед запуском кампании.
2. **Смысловая адаптация (No Machine Translation)**:
   - Не использовать дословный машинный перевод; применять принятый в израильском хайтеке стандарт иврита (עברית של הייטק, например `אודיט AI`, `טופסי לידים`, `נראות בחיפוש AI`) и US Tech Standard для английского языка.
